# 🎶 猜歌词游戏

一款基于纯 HTML/CSS/JS 的中文歌词猜字小游戏，无需任何框架，开箱即玩。

## 效果预览

选择专场 → 随机抽取歌曲 → 逐字猜测揭示歌词 → **歌名全部揭示即获胜**

支持键盘 `Enter` 快速提交，移动端友好（最大宽度 500px）。

## 游戏规则

1. 选择一个音乐专场进入游戏
2. 在输入框中输入**汉字、字母或数字**进行猜测
3. 命中的字符在歌词和歌名中同步揭示（绿色高亮）
4. **歌名所有字符全部揭示**即算获胜
5. 点击「提示 +2次」可随机揭示一个未知字符，但猜测次数 +2

## 预揭示规则

高频虚词默认预先显示，不消耗猜测次数：

```
的  了  是  在  着  你  我  他
```

## 胜利统计

获胜后弹窗展示：

- 本局猜测总次数
- 本局用时（自动换算分钟/秒）

可选择「再来一首」继续当前专场，或「换个专场」回到主页。

## 快速开始

直接用浏览器打开 `song/index.html` 即可，**无需安装任何依赖**。

```bash
# 或用任意静态服务器预览
npx serve .
```

## 扩展歌曲数据

歌曲数据统一维护在 `song/songs-data.js`，格式如下：

```javascript
// 在对应专场的数组里追加即可
{ name: "歌曲名称", artist: "歌手名", lyrics: [
    "第一行歌词",
    "第二行歌词",
    "第三行歌词",
    // 建议 8~16 行
]},
```

新增专场只需在 `THEMES` 数组添加配置，并在 `THEME_SONGS` 中添加对应 key：

```javascript
// THEMES 添加
{ id: 'newtheme', name: '新专场', icon: '🎼', desc: '专场描述' }

// THEME_SONGS 添加
newtheme: [
    { name: "...", artist: "...", lyrics: [...] },
]
```

## 对接真实接口

游戏已预留接口层，只需在 `index.html` 的 `fetchSong()` 函数中取消注释并替换接口地址：

```javascript
const res = await fetch(`/api/songs/random?theme=${themeId}`);
if (res.ok) return await res.json();
```

**接口返回格式：**

```json
{
  "name": "歌曲名称",
  "artist": "歌手名 / 歌手名",
  "lyrics": ["第一行歌词", "第二行歌词", "..."]
}
```

未对接接口时自动使用本地数据兜底，不影响游戏流程。
