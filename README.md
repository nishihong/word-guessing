# 🎶 猜歌词游戏

一款基于纯 HTML/CSS/JS 的中文歌词猜字小游戏，无需任何框架，开箱即玩。

## 效果预览

- 选择专场 → 随机抽取歌曲 → 逐字猜测揭示歌词 → 歌名全部揭示即获胜
- 支持键盘 `Enter` 快速提交，移动端友好（最大宽度 500px）

## 游戏规则

1. 选择一个音乐专场进入游戏
2. 在输入框中输入**汉字、字母或数字**进行猜测
3. 输入的字符若出现在歌词或歌名中，对应位置会被揭示（绿色高亮）
4. **歌名所有字符全部揭示**即算获胜
5. 使用「提示 +2次」按钮可随机揭示一个未知字符，但会增加 2 次猜测计数

## 胜利统计

获胜后弹窗展示：
- 猜测总次数
- 用时（秒/分钟）

## 快速开始

直接用浏览器打开 `song/index.html` 即可，**无需安装任何依赖**。

```bash
# 或用任意静态服务器
npx serve .
```

## 对接真实接口

游戏已预留接口层，只需在 `fetchSong()` 函数中取消注释并替换接口地址：

```javascript
// song/index.html - fetchSong() 函数
const res = await fetch(`/api/songs/random?theme=${themeId}`);
if (res.ok) return await res.json();
```

**接口返回格式：**

```json
{
  "name": "歌曲名称",
  "artist": "歌手名 / 歌手名",
  "lyrics": [
    "第一行歌词",
    "第二行歌词",
    "第三行歌词"
  ]
}
```

未对接接口时自动使用本地占位数据兜底，不影响游戏流程。
